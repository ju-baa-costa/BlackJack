# Blackjack
Esse projeto foi feito tendo como inspiração o desafio de criar um jogo de Blackjack da plataforma Scrimba, porém com um adicional: o Dealer.
## O desafio:
Criar um site pelo qual se poderia jogar blackjack (ou 21), com um design simples, que possa ser usado em formato mobile ou desktop. O Dealer segue a sequÊncia lógica da regra original, comprando até obter a soma de 17 ou mais, e então comparando com a soma do jogador. Já no caso de um empate, uma disputa de carta maior é feita.
## Tecnologias usadas:
Foram utilizados HTML, CSS e JavaScript.
## Aprendizados:
Com esse exercício, sendo meu primeiro projeto com JavaScript, me familiarizei com funções, sintaxe e com como combinar as funções dessa linguagem com o front-end criado.
